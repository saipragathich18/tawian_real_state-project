# Taiwan Real Estate Price Prediction

## Project Overview
This project predicts house prices using Taiwan real estate dataset.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Steps Performed
- Data Cleaning
- Exploratory Data Analysis
- Train Test Split
- Linear Regression Model
- Model Evaluation (MAE, RMSE, R2 Score)

## Result
Built a machine learning model to predict real estate prices.
